# JHC Web Development Page

## This repository is for preproduction for main website

🌐 JHC Web Development

Preproduction environment for the JHC main website.

Welcome! 👋 This repository contains the web development and preproduction code for the JHC main website.

🚧 About This Repository

This is where new features, updates, designs, and other website changes are developed and tested before being deployed to the production website.

🔄 Development Workflow
Development → Testing → Preproduction → Production


Changes made here should be reviewed and tested thoroughly before making their way to the live website.

📁 Repository Purpose

🛠️ Develop new website features

🎨 Test UI and design changes

🧪 Validate updates in a preproduction environment

🐛 Identify and fix issues before production

🚀 Prepare changes for deployment

Note: This repository is intended for development and preproduction purposes and may contain features or changes that are not yet ready for the live website.
